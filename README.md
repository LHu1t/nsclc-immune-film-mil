# NSCLC Immune Profiling — FiLM-MIL

Deep learning pipeline for subtype-specific immune gene expression 
prediction from H&E whole-slide images in NSCLC.

## Structure
- `src/` — training and feature extraction scripts
- `notebooks/` — Kaggle training notebooks
- `scripts/` — cluster submission scripts
- `results/` — evaluation outputs (JSON, figures)
